# 日本の地名の由来ナレッジベース

日本の都道府県・市区町村の名前の由来を、一次文献まで遡った出典つきで記録するナレッジベースです。主張は「歴史的事実」と「民間伝説」に分けて記録し、諸説が対立するものは両論を併記します。本リポジトリの内容は基本的にAIが調査・作成したもので、出典と証拠レベルを付けて公開しています。

## 現在の収載

- 都道府県：現時点で45件以上のレコード（主張は380件以上＝歴史的事実と民間伝説を分離、出典は200件以上）
- 市区町村：地図データに現時点で1,700件以上を収載。由来レコードは現時点で1,700件以上を作成済みで、所属未定地を除くすべての自治体をカバーしています（レコードのある自治体は地図上で色が変わります）

正確な件数はサイト下部の統計（データから自動計算）をご覧ください。

## 構成

- `files/meta-design.md` — 設計の正本（母集団、証拠レベル、事実と伝説の分離、同名地名の扱い、コラムの方針）
- `files/prefecture-records.yaml` — 都道府県レコードの正本（L1）。サイトとJSONはここから生成します
- `files/municipality-records.yaml` — 市区町村レコードの正本（L1）。出典レジストリは都道府県レコードと共有し、同一URLは都道府県側のキーで参照します。リポジトリ収載時はファイルサイズの都合により県別に分割し、`files/muni-yaml/<県コード>.yaml`（各ファイルは自県レコードが参照する出典を同梱）として置いています
- `files/population-prefectures.yaml` / `files/population-municipalities.yaml` — 網羅を測る母集団
- `site/` — 静的サイト。`site/index.html` が地図アプリ、`site/data/` に生成済みJSONと地図データ
- `data/muni-records/<県コード>.json` — 市区町村レコードのサイト配信用JSON（都道府県別に分割し、開いた県の分だけ読み込む形）。全件検索用の軽い索引は `data/muni-search-index.json`、統計は `data/muni-stats.json`
- `scripts/` — 統合・分割などの処理スクリプト

## 地図データについて

地図データは、国土数値情報（行政区域データ・2026年版）（国土交通省）を加工して使用しています。都道府県データ（47件）は GeoJSON のまま、市区町村データ（都道府県別）は転送量を抑えるため、座標を小数第5位（約1m）の格子で符号化したコンパクト形式（`data/muni-enc/`、GeoJSON から生成・復号でき、格子の範囲では無劣化）で同梱しています。投影は経緯度を線形にSVG座標へ写像する方式です。

## 証拠レベル

E1 一次文献／E2 公的・学術の二次資料／E3 専門文献／E4 地域の証言・郷土資料／E5 出典不明の一般情報／H 類推。二次資料経由でしか確認できない一次文献の記載は、レベルを落として「公式が紹介」という形で記録しています。
